# Ёмкость спринта: демонстрационный расчёт

Методика: часы задач складываются и сравниваются с доступной ёмкостью команды.

| Задача | Оценка |
|---|---:|
| Добавить страницу для самых последних учебников | 5 ч |
| Оптимизация запроса к данным для последних учебников | 3 ч |
| **Итого** | **8 ч** |

Реальная ёмкость участника не задана в методичке как актуальная дата: Codex должен указать принятые допущения, не выдумывать коллег и привязать записи к существующим Issues.
