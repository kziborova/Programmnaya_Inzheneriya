# Scrum: организация работ

Работа ведётся в учебных командах `PUL-Web` и `External integrations`. На GitHub используется модель Issues + Projects с полями итераций и приоритетов. Названия команд отражаются метками, а не автономными Azure Teams.

- Эпик: «Обучение продуктам».
- Функция: «Осваиваем дашборды».
- Истории: новые учебники, недавно просмотренные учебники, запрос новых материалов.
- Задачи: отображение новых учебников (5 ч), оптимизация запроса данных (3 ч).

Создаваемые Codex ссылки на настоящие Issues/Projects следует добавить в отчёты лабораторных.
