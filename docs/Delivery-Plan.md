# План поставки веб-приложения

Нужен GitHub Projects Roadmap с итерациями, датами задач и внешней командой. Сюжеты из методички: погодная интеграция и интеграция данных о доставках. Зависимость задачи слежения за посылками от данных о доставках должна быть **явно видна**. При корректировке плана интеграция доставки переносится раньше, погодная интеграция — позже.

Фактические даты/ссылки вводятся после создания GitHub Project. Даты должны соответствовать моменту выполнения работы.
