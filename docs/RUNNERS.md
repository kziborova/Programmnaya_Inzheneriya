# Исполнитель сборки

В CI задача test-and-build выбирает образ ubuntu-latest через runs-on. GitHub выделяет машину на время задания. Шаг setup-python подготавливает Python 3.12. Локальные проверки выполнены на macOS arm64. Фактический образ и версию Linux можно проверить в журнале Set up job после запуска.

В Azure capabilities сопоставляются с demands. Для собственного runner в GitHub подбор выполняется по меткам (например, self-hosted, macOS, ARM64), а доступ к репозиториям ограничивается группой runner. Регистрация личного Mac требует отдельного разрешения. В текущем проекте используется конфигурация hosted.
