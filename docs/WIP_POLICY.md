# Kanban и ограничения незавершённой работы

Статусы: Backlog → Approved → Coding → QA Approved → Done.

Для стадии **QA Approved** целевой **WIP = 1**. При нахождении двух и более задач в стадии следует явно фиксировать превышение в отчёте и возвращать одну задачу на предыдущую стадию.

**Важно:** это описанная процессная политика; она **не является гарантированным автоматическим лимитом в GitHub Projects**. Для эквивалента swimlane «Ускоренная» используется метка `expedite`.
