# Начало работы

1. Клонируйте репозиторий.
2. Проверьте Python 3.10+.
3. Запустите `python3 -m unittest discover -s tests -v`.
4. Выполните `python3 scripts/build_site.py`.
5. Для локального просмотра выполните `python3 -m http.server 8000 --bind 127.0.0.1 --directory dist`.
6. Для задач и планирования откройте вкладки `Issues` и связанный GitHub Project.

В целях конфиденциальности проект не должен содержать PAT, пароли и приватные PDF.

## Проверка страницы материала

На странице каталога выберите «Открыть материал». Адрес вида `material.html?id=new-1` можно открывать напрямую. Автор, категория, год и содержание выводятся при наличии полей `author`, `category`, `year` и `content` в записи JSON. Три занятия содержат введение, основные понятия, практику и вывод. Поле content содержит разделы с абзацами, списками и примерами команд. При неизвестном идентификаторе доступен возврат в каталог.

Для проверки в Chrome запустите локальный сервер, затем выполните из корня проекта `node --test tests/material.browser.cjs` в окружении с Node.js, Playwright и установленным Google Chrome. Тест открывает учебники, проверяет историю, форму заявки, необязательные поля и значок вкладки. Обе страницы используют одну версионную иконку книги, а в корне сборки есть запасной favicon.ico.
