# Лабораторные работы по программной инженерии

![Эмблема Parts Unlimited Academy](docs/assets/academy.svg)

**Parts Unlimited Academy** — учебный каталог с тремя занятиями по Git, Kanban и GitHub Actions. У каждого занятия есть пояснение, практический пример и вывод.

**[Открыть каталог на этом компьютере](http://127.0.0.1:8000/index.html)**

Ссылка работает, когда на этом компьютере запущен локальный сервер. Если он уже работает, можно сразу выбрать учебник.

[Документация проекта](docs/Home.md) · [Все девять лабораторных](docs/labs/README.md)

## Что посмотреть

В каталоге нажмите «Открыть материал». Прочитайте занятие и выберите «Вернуться к каталогу». Учебник появится в разделе «Недавно просмотренные», откуда его можно открыть повторно. Внизу страницы можно запросить новый материал. История и заявки сохраняются в текущем браузере.

## Запуск на Mac

В Терминале откройте папку проекта, где находятся каталоги `site` и `scripts`. Проверьте файлы, соберите сайт и запустите сервер:

```bash
python3 -m unittest discover -s tests -v
python3 scripts/build_site.py
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

Оставьте Терминал открытым и перейдите в каталог по ссылке в начале страницы. Чтобы остановить сервер после показа, нажмите Ctrl+C.
